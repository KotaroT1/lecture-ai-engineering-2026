# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
  - Gemini 3系の `gemini-3.5-flash-lite` では3回とも、講座固有の定義ではなく「初級・中級・上級」や
    「理解・応用・発展」のような一般的な3段階だと推測していた。回によってはAIE2026を
    別のAI教育プログラムかもしれないと推測し、公式資料や講師に確認するよう促していた。
  - 同じくGemini 3系の `gemini-3.1-flash-lite` でも、AI開発の習熟度や課題難易度の3段階だと推測した。
    1回は「知識・実装・分析」の段階として説明し、回答の切り口は毎回異なった。
- 用語集の正しい意味と比べて気づいたこと：
  - 正しい定義は「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展
    （調査や試行）」の3段階で、どれか1つに取り組めば宿題を完了でき、原則採点はない、
    という宿題の構成である。
  - モデルはこの講座の用語集を参照していないため、正しい定義を知らず、もっともらしい
    一般論を断定調で生成した。質問を同じにしても、レベルの意味や具体例が毎回変わった。
- 表示できたトークン数（入力 / 出力）：
  - Gemini 3系 `gemini-3.5-flash-lite`：21 / 523、21 / 595、21 / 621
  - Gemini 3系 `gemini-3.1-flash-lite`：21 / 714、21 / 668、21 / 619
  - 入力は同じ質問なので毎回21トークンだったが、出力は回答内容に応じて変化した。

## 宿題

- 取り組んだレベル：基礎
- やったこと：
  - 同じ質問「AIE2026の講座の宿題にある『3レベル』とは何ですか？」を、
    Gemini 3系の `gemini-3.5-flash-lite` と `gemini-3.1-flash-lite` でそれぞれ3回ずつ実行した。
    モデルは `AIE_MODEL` 環境変数で切り替えた。ここでいう「gemini-3」はモデル系列の呼び方であり、
    実際に指定したモデル名は上記の2つである。
  - 追加で質問を「LoRAとは何ですか？」に変更し、`gemini-3.5-flash-lite` に対して
    `temperature=0.0` と `temperature=1.0` を各3回指定して実行した。
    `generate_content` の `config` に `GenerateContentConfig(temperature=...)` を渡した。
- 結果：
  - どちらのモデルも講座の正しい定義を答えず、一般的な「初級・中級・上級」や
    「理解・応用・発展」として説明した。6回の回答は同じモデルでも表現や想定する
    分類が揺れた。
  - 出力トークン数は `gemini-3.5-flash-lite` が523〜621、`gemini-3.1-flash-lite` が
    619〜714で、比較モデルのほうが今回の質問では長い回答になった。
  - 比較実行中に一度503（モデルが混み合っている）が発生した。少し待って再実行すると
    成功したため、回答の違いにはモデルの確率的な揺れだけでなく、無料枠の混雑も影響しうる。
  - LoRAへの回答は、`temperature=0.0`、`1.0` のどちらも「Low-Rank Adaptation
    （低ランク適応）」の略で、モデル本体を凍結して小さな追加パラメータだけを学習する
    効率的なファインチューニング手法だと説明しており、内容は正しかった。
  - `temperature=0.0` の出力トークン数は562、577、610、`temperature=1.0` は680、634、
    598だった。`temperature=0.0` では説明が比較的簡潔で、`temperature=1.0` では
    従来のファインチューニングとの違いや計算コストなどの補足が増えた。ただし各3回
    だけなので、温度による傾向と断定はできない。
- 気づき・疑問：
  - LLMは知らない固有情報でも、確認できていないことを明示しないまま具体例を添えて
    説明できる。回答の流暢さだけでは正しさを判断できないため、用語集や検索ツールなど
    の根拠を参照させる必要がある。
  - モデルを変えると出力の長さや説明の観点は変わったが、講座固有の知識がないという
    問題自体は解消しなかった。
  - temperature を下げても、今回の実行では回答が完全に固定されたわけではなかった。
    temperature は回答のランダム性や多様性に影響する設定だが、正確な知識を追加する
    設定ではない。今回のLoRAのような一般用語では両温度とも正しく答えた一方、講座固有
    の「3レベル」では両温度とも根拠のない一般論になったため、正確さには温度よりも
    用語集などの根拠を参照できる仕組みが重要だと分かった。
